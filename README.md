# MedGramma — Live Cataract Surgery Co-Pilot

MedGramma is a browser-based co-pilot tool designed to assist during live cataract surgery. Built as a standalone HTML application, it runs entirely in the browser with no installation required.

## Features

- **Live Surgery Co-Pilot** — Real-time guidance interface tailored for cataract surgery workflows
- **Standalone & Portable** — Single `.html` file, no server or backend needed
- **Offline Capable** — All assets are bundled and self-contained within the file

## Getting Started

### Run Locally

1. Download `MedGramma.html`
2. Open it in any modern browser (Chrome, Edge, Firefox)
3. No installation or setup required

### View Online

This project is hosted via GitHub Pages:

> **[https://LiewXinWei.github.io/-MedGramma/MedGramma.html](https://LiewXinWei.github.io/-MedGramma/MedGramma.html)**

## Tech Stack

- Pure HTML/CSS/JavaScript
- All assets bundled and base64-encoded within a single file
- Designed with Canva, exported as standalone HTML

## Requirements

- A modern web browser with JavaScript enabled
- No internet connection required after download
